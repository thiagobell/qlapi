What the API offers

Everything the UI does is a plain HTTP call — use it from scripts, bots or other apps. Interactive documentation lives at /docs.

MethodPathWhat it does
GET/health Reachability status of the configured printer(s).
GET/labels Label stock supported by the printer: sizes, printable dots, default.
POST/job Queue a print. Multipart label_file (png/jpg/jpeg/pdf), plus rotate and copies options. Returns a job id.
GET/job/{job_id} Poll a queued print job until it is done or failed.
GET/templates List saved label templates.
GET/templates/{id} Fetch one template, including its canvas definition.
POST/templates Save a new template (name, label_identifier, canvas).
POST/templates/{id} Overwrite an existing template.
DELETE/templates/{id} Delete a template.
GET/editor The label editor UI, embedded above.
